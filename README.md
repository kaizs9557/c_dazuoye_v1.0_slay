## 项目简介

这是一个用 C 语言实现的命令行卡牌战斗游戏。玩家通过抽牌、出牌、选择攻击目标、结束回合，与不同敌人进行战斗。游戏包含多个关卡、卡牌奖励、敌人 AI、遗物系统和日志记录。

当前版本实现了基础战斗循环、5 个关卡、3 种敌人、约 33 张卡牌、9 种遗物以及简单的敌人效用 AI。

## 环境与依赖

- C11 编译器，如 `gcc`、`clang`
- CMake 3.22 或更高版本
- 数学库 `m`
- 建议在 Linux / macOS / WSL 下运行
- 代码使用了 `<unistd.h>` 中的 `sleep()`，Windows 原生环境可能需要额外适配


## 操作说明

游戏启动后，按照提示输入：

- 输入卡牌编号：打出对应手牌
- 输入 `0`：结束当前回合
- 输入 `quit`：退出游戏
- 攻击类卡牌需要选择攻击目标
- 状态牌无法主动打出
- 能量不足时无法打出对应卡牌

每回合默认抽 5 张牌，初始能量为 3。手牌上限为 12。

## 游戏流程

1. 创建关卡
2. 初始化玩家与敌人
3. 随机获得遗物
4. 开始新回合，抽取手牌
5. 玩家出牌或结束回合
6. 敌人 AI 选择行动并执行
7. 判断胜负
8. 胜利后获得金币、选择奖励卡牌
9. 进入下一关或结束游戏

## 卡牌系统

初始牌组：

- 打击 ×5
- 格挡 ×5
- 痛击 ×1

当前已实现卡牌约 33 张，其中奖励卡池约 30 张：

愤怒、头槌、双重打击、剑柄打击、重刃、铁波、完美打击、回旋镖、雷鸣攻击、狂野打击、全身撞击、交锋、顺劈斩、金刚臂、飞身踢、御血术、连续拳、暴走、无谋冲锋、灼热攻击、断魂斩、上勾拳、以血还雪、旋风斩、残杀、狂宴、恶魔之焰、幡祭、死亡收割、重锤。

卡牌类型：

- 普通牌：打出后进入弃牌堆
- 消耗牌：打出后进入消耗堆 `graveyard`
- 虚无牌：若留在手中，回合结束时进入消耗堆
- 状态牌：无法主动打出

部分特殊机制：

- `旋风斩` 为 X 费牌，消耗当前所有能量
- `狂宴` 若击杀目标，提升最大生命值
- `恶魔之焰` 消耗手牌并造成伤害
- `死亡收割` 根据造成伤害回复生命

## 敌人与 AI

当前敌人：

| 敌人 | 特点 | 行动 |
| --- | --- | --- |
| 大鳄虫 | 基础敌人，第一回合倾向重击 | 重击、盾击、吼叫 |
| 小史莱姆 | 低血量，多体出现 | 攻击、刺击 |
| 乐加维林 | 精英敌人，前 3 回合沉睡 | 沉睡、重击、灵魂抽取 |

敌人 AI 通过效用函数计算每个行动的分数，选择效用最高的行动。效用会考虑回合数、敌我血量、格挡、力量、是否近期受伤等因素。

## 已知问题与改进方向

当前项目仍有不少可改进之处：

- 全局变量 `game_state` 与函数参数 `state` 存在混用
- `CARD_IMMOLATE` 插入状态牌时使用了 `state->hand` 和 `hand_size`，可能应为 `pile` 和 `pile_size`
- `select_random_relic` 使用 `rand() % 8`，但遗物数组有 9 个，奇异甜圈圈可能无法随机到
- 反击项链在 `enemy.c` 中按 25% 反弹，在 `relic.c` 中函数按 10% 反弹，数值不一致
- 部分遗物重复获得时没有去重
- `CARD_CLASH` 未检查手牌是否全为攻击牌
- `CARD_HEADBUTT` 选择弃牌堆索引时缺少边界检查
- Windows 原生环境对 `unistd.h` 和 `sleep()` 支持不佳
- 药水系统只有声明，尚未实现
- 大量卡牌枚举已预留，但尚未实现具体效果
- 日志系统只支持极少数格式符
